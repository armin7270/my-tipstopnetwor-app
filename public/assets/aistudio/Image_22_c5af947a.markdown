## Brand & Style

This design system defines an ultra-modern, visceral utility interface for high-throughput networking tools. The aesthetic synthesizes Apple's fluid "Liquid Glass" optical materials with high-density Android Jetpack Compose ergonomics, tailored specifically for technical privacy engines and low-level proxy/VPN clients.

### Aesthetic Tone
- **Hyper-tactile Transparency**: Dynamic glass panels, optical index refraction, and layered specular light borders create deep visual z-indexing over an absolute deep space canvas.
- **Cybernetic Precision**: High-frequency telemetry (ping jitter, packet throughput, cryptographic handshake state) is presented with calm, scannable clarity rather than cluttered terminal logs.
- **Atmospheric Reactivity**: Color is living feedback; the interface pulses with dormant cyan during idle routing and shifts to sharp crystalline emerald upon tun2socks encapsulation.

### Emotional Target
The user experiences supreme digital sovereignty, speed, and structural integrity. The application feels frictionless, military-grade, and engineered rather than merely assembled.

## Colors

The palette is engineered exclusively for an immersive, pure OLED dark environment. It utilizes a midnight obsidian foundation paired with high-luminance coherent cyan and emerald laser indicators.

### Key Palettes
- **Deep Obsidian (Neutral Canvas - `#0B0F19`)**: Deepest substrate layer, calibrated to conserve battery life and maximize the perceived luminous depth of glass sheets.
- **Sub-surface Container (`#111827`)**: Elevates inactive modules and structured list wrappers.
- **Photon Cyan (Primary - `#00F2FE`)**: The active frequency of the system. Used for core telemetry lines, primary toggles, active routing nodes, and high-priority visual anchors.
- **Flux Blue (Tertiary - `#4FACFE`)**: Creates continuous dual-tone liquid gradients alongside Photon Cyan to indicate active routing and packet encryption.
- **Encrypted Emerald (Secondary - `#10B981`)**: The state of complete isolation and security. Signifies established tun2socks tunnels, zero packet drops, and optimal ping states (< 80ms).
- **Signal Amber (`#F59E0B`)**: Handshake latency, route bypass, or fallback protocol routing.
- **Core Crimson (`#EF4444`)**: Route termination, proxy loop errors, Xray kernel panics, and kill-switch activation.

## Typography

The type system is tailored for cross-lingual parity between technical English strings and Persian localization scripts.

### Font Pairing Strategy
- **Headlines & Metric Callouts (`Space Grotesk`)**: Technical, geometric, and distinctively modern. Used for primary state summaries, connection status headings, and mega-stats.
- **Body & Controls (`Inter`)**: High-legibility neutral sans-serif handling general settings, server node lists, descriptions, and standard UI copy. When rendered in Persian locales, falls back cleanly to matched baseline weight in **Vazirmatn**.
- **Telemetry & Protocols (`JetBrains Mono`)**: Strict tabular alignment for live upload/download speed counters, byte trackers, IP/Port notations, routing rule regex, and millisecond ping markers.

## Layout & Spacing

Designed primarily for single-handed mobile navigation in high-stress interaction environments, adapting dynamically to foldables and tablet splits.

### Layout Mechanics
- **Grid Structure**: 4-column dynamic grid on mobile devices (320dp - 599dp) with strict 16dp outer margins. 8-column layout on foldables and tablets (600dp+) with persistent side telemetry.
