# Android wrapper

A minimal, dependency-free WebView shell that packages the built web interface as an
installable APK. It contains **no native libraries**, so one universal APK runs on
`arm64-v8a`, `armeabi-v7a`, `x86` and `x86_64` Android devices.

> This is a UI wrapper, not a VPN client: the interface still simulates its telemetry.
> See [../docs/BUILD-ANDROID.md](../docs/BUILD-ANDROID.md) for the native pieces a real
> tunnel requires (`VpnService`, `tun2socks`, per-ABI `.so` files).

## Requirements

- JDK 17+
- Android SDK with `platforms;android-35` and `build-tools;35.0.0`
- `JAVA_HOME` and `ANDROID_HOME` exported

## Build

From the repository root:

```bash
npm ci
npm run apk              # release build (or debug when no keystore is configured)
```

The helper script builds the web bundle with a **relative base** into `dist-android/`,
runs Gradle, and copies the result into `release/` together with `SHA256SUMS.txt`.

Manual equivalent:

```bash
npm run build:android
cd android
./gradlew assembleRelease      # Windows: gradlew.bat assembleRelease
```

## Signing

Credentials are read from `android/keystore.properties` (git-ignored) or `OBSIDIAN_*`
environment variables:

```properties
storeFile=/absolute/path/release.jks
storePassword=********
keyAlias=obsidian
keyPassword=********
versionCode=1
versionName=1.0.0
```

Generate a keystore once and keep it somewhere safe — losing it means you can no longer
ship updates to the same application id:

```bash
keytool -genkeypair -v -keystore release.jks -alias obsidian \
        -keyalg RSA -keysize 4096 -validity 10000
```

Without a keystore, `assembleRelease` produces an **unsigned** APK that cannot be
installed; use `npm run apk -- --debug` for a sideloadable debug build instead.

## Notes

- `versionCode` / `versionName` default to `1` / `package.json` version.
- The launcher icons are generated from `public/favicon.svg`.
- `android/app/src/main/assets/www` is generated by Gradle and git-ignored.
- CI builds the APK on every `v*` tag — see `.github/workflows/android-apk.yml`.
